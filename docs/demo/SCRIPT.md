# Demo video script — 3:55

**Setup**

- **Build:** open the game with **`?video&seed=97`**, e.g. `http://localhost:5173/?video&seed=97` or the deployed link with `?video&seed=97`. The game then plays exactly these moments in this order (`src/app/demoVideo.ts`).
- **Persona:** the **scholarship** student. Their scam call is the "ePASS officer".
- **Sound:** ♪ panel → Music ON, Sound effects ON, Voice-over ON. The Professor, the callers and the explainers are voiced by the game itself, so the narrator only speaks where the game is quiet.
- **Screen:** portrait, phone-sized (360×640 window, or a phone).

Each row below lists, in order: what to tap, what's on screen, and the **caption** (on-screen text) and **narrator** line.
